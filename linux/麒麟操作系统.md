# yum源配置

- yum源路径

- yum源配置
  
  ```
  vim /etc/yum.repos.d/kylin_x86_64.repo
  yum clean all
  yun makecache
  yum list kernel*
  ```

- 切换内核

- ```
  sudo yum install kernel-4.19.90-89.24.v2401.ky10.x86_64 \
   kernel-core-4.19.90-89.24.v2401.ky10.x86_64 \
   kernel-modules-4.19.90-89.24.v2401.ky10.x86_64 # 安装核心组件:ml-citation{ref="2,7" data="citationList"}
  
  sudo grub2-mkconfig -o /boot/grub2/grub.cfg # 生成新启动菜单:ml-citation{ref="8" data="citationList"}
  sudo grub2-set-default "Kylin Linux Advanced Server (4.19.90-89.24.v2401.ky10.x86_64)"
  sudo reboot
  ```
