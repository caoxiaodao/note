## 数据库时区

![](../image/知识积累/2025-04-16-19-06-43-image.png)

  timestamp：存储时转换为utc存储、读取时根据会话时区转为客户端（会话）时区

  datetime：存储时原样存储应用传递的时间、读取时原样输出

  long时间戳（依赖应用、不受数据库时区限制）

- `NOW()`、`CURTIME()` 等函数返回的时间基于**当前会话时区**。

- `UTC_TIMESTAMP()` 始终返回UTC时间。
