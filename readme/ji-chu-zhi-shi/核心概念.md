## 相关度评分算法

### TF/IDF

**平均的出现所有重要的词项**

词频：词频高相关度评分高

score(q, d)  =  queryNorm(q)  *  coord(q,d)  *  ∑ [ (tf(t in d)  *  idf(t)²  *  t.getBoost()  *  norm(t,d) ) ] (t in q)
